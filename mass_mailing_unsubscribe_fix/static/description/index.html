Mass Mailing Unsubscribe Fix

Fixes 404 errors in unsubscribe links

Problem Solved

In Odoo Premium, users clicking the unsubscribe button in email templates received 404 errors because the URL replacement logic was not working correctly for relative URLs in templates.

How It Works

This module overrides the _send_prepare_values method in mail.mail to properly handle both absolute and relative URLs in email templates, ensuring the unsubscribe links work correctly.

Installation

Simply install this module and restart your Odoo server. The fix will be automatically applied to all new and existing email templates.
